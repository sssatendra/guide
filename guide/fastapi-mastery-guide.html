01 • Fundamentals

Getting Started with FastAPI

FastAPI is a modern, high-performance Python web framework built on top of Starlette and Pydantic. It leverages async/await for concurrent request handling and automatic API documentation.

First Application

main.py 
from fastapi import FastAPI
from uvicorn import run

app = FastAPI(title="My API", version="1.0.0")

@app.get("/")
async def root():
    return {"message": "Hello, FastAPI!"}

# Run with: uvicorn main:app --reload
Code Breakdown:

• FastAPI() — Creates the main application instance for routing

• @app.get("/") — Decorator registers HTTP GET handler on root path

• async def — Enables concurrent request handling with asyncio

• uvicorn — ASGI server that runs your application

• --reload — Auto-restarts server on code changes (development only)

💡 Key Insight: FastAPI automatically generates interactive API docs at /docs (Swagger UI) and /redoc (ReDoc) based on type hints—no manual documentation needed!

Why FastAPI?

⚡

High Performance

Async/await support with automatic OpenAPI schema generation for blazing-fast throughput.

📝

Auto Documentation

Interactive Swagger UI and ReDoc generated automatically from type hints.

✅

Data Validation

Built-in Pydantic validation with automatic error messages and JSON Schema.

🔒

Security

Multiple security schemes: OAuth2, API Keys, JWT with intuitive decorators.

02 • Routing & Path Parameters

HTTP Methods & Path Parameters

routing_advanced.py 
from fastapi import FastAPI, HTTPException
from enum import Enum

app = FastAPI()

class ModelName(str, Enum):
    alexnet = "alexnet"
    resnet = "resnet"
    lenet = "lenet"

# Path parameter with type validation
@app.get("/items/{item_id}")
async def get_item(item_id: int):
    # item_id automatically converted to int
    return {"item_id": item_id}

# Enum validation
@app.get("/models/{model_name}")
async def get_model(model_name: ModelName):
    if model_name == ModelName.alexnet:
        return {"model": "AlexNet CNN"}
    return {"model": model_name}

# Multiple path parameters
@app.get("/users/{user_id}/items/{item_id}")
async def get_user_item(user_id: int, item_id: str):
    return {"user_id": user_id, "item_id": item_id}

# All HTTP methods
@app.post("/items/")
async def create_item(name: str):
    return {"created": name}

@app.put("/items/{item_id}")
async def update_item(item_id: int, name: str):
    return {"item_id": item_id, "updated": name}

@app.delete("/items/{item_id}")
async def delete_item(item_id: int):
    return {"deleted": item_id}
Understanding Path Parameters:

• Type Hints — FastAPI validates and converts path parameters to specified types (int, str, float, UUID, date)

• Enum Validation — Restricts parameters to predefined values, automatically documented in API

• Order Matters — More specific routes (/items/me) should come before generic ones (/items/{id})

• Path Operators — GET, POST, PUT, PATCH, DELETE map directly to CRUD operations

✅ Best Practice: Use path parameters for resource identification (/users/{id}) and query parameters for filtering or pagination (/items?skip=0&limit=10).

03 • Request & Response Handling

Query Parameters & Request Body

request_handling.py 
from fastapi import FastAPI, Query
from pydantic import BaseModel

app = FastAPI()

# Query parameters with defaults
@app.get("/items/")
async def list_items(
    skip: int = 0,
    limit: int = 10,
    q: str = None
):
    return {"skip": skip, "limit": limit, "search": q}

# Request body with Pydantic model
class Item(BaseModel):
    name: str
    price: float
    description: str = ""
    tax: float = None

@app.post("/items/")
async def create_item(item: Item):
    return {"item": item, "total": item.price + (item.tax or 0)}

# Multiple body parameters
class User(BaseModel):
    name: str
    email: str

@app.post("/purchase/")
async def purchase(user: User, item: Item):
    return {"user": user, "item": item}

# Query parameters with validation
@app.get("/search/")
async def search(
    q: str = Query("", min_length=1, max_length=50),
    skip: int = Query(0, ge=0),
    limit: int = Query(10, le=100)
):
    return {"query": q, "skip": skip, "limit": limit}
Request Handling Details:

• Query Parameters — Appended to URL (?skip=0&limit=10), optional by default

• Request Body — JSON payload sent in POST/PUT/PATCH, must be Pydantic model

• BaseModel — Pydantic class for data validation and serialization

• Query() — Adds metadata and validation constraints to query parameters

• Type Hints — Optional fields use None default, required fields have no default

Response Models & Status Codes

from fastapi import FastAPI, status
from typing import List

class Item(BaseModel):
    id: int
    name: str
    price: float

class ItemResponse(BaseModel):
    id: int
    name: str
    # Note: price not included in response

✅ Pro Tip: Use response_model to define what data is returned to clients. Pydantic automatically filters sensitive fields like passwords or internal IDs.
04 • Data Validation & Pydantic Models

Advanced Validation Techniques

validation.py 
from pydantic import BaseModel, Field, validator, EmailStr
from typing import Optional, List
from datetime import datetime

class User(BaseModel):
    # Field constraints
    username: str = Field(..., min_length=3, max_length=50)
    email: EmailStr  # Validates email format
    age: int = Field(..., ge=0, le=150)  # ge=greater or equal, le=less or equal
    bio: Optional[str] = Field(None, max_length=500)
    tags: List[str] = Field(default_factory=list)
    
    # Custom validation
    @validator('username')
    def username_alphanumeric(cls, v):
        if not v.isalnum():
            raise ValueError('must be alphanumeric')
        return v
    
    # Cross-field validation
    @validator('age')
    def validate_age(cls, v, values):
        if v < 18 and 'username' in values:
            raise ValueError('Users under 18 cannot have accounts')
        return v

    class Config:
        schema_extra = {
            "example": {
                "username": "johndoe",
                "email": "john@example.com",
                "age": 25,
                "bio": "Python developer",
                "tags": ["python", "fastapi"]
            }
        }
Validation Components:

• Field(...) — Marks field as required, adds constraints (min_length, max_length, ge, le)

• EmailStr — Pydantic type that validates email format (requires pydantic[email])

• @validator — Custom validation logic applied to individual or multiple fields

• Config.schema_extra — Adds example payloads to OpenAPI documentation

05 • Dependency Injection

Reusable Dependencies & DI Pattern

dependencies.py 
from fastapi import FastAPI, Depends, Query

app = FastAPI()

# Basic dependency
async def common_parameters(
    skip: int = Query(0, ge=0),
    limit: int = Query(10, le=100)
):
    return {"skip": skip, "limit": limit}

@app.get("/items/")
async def list_items(commons: dict = Depends(common_parameters)):
    return {"items": [], "params": commons}

# Dependency on dependency
async def get_current_user():
    return {"user_id": 1, "username": "john"}

async def get_user_permissions(user = Depends(get_current_user)):
    return {"user": user, "permissions": ["read", "write"]}

@app.get("/protected/")
async def protected_route(perms = Depends(get_user_permissions)):
    return perms

# Dependency class
class Database:
    def __init__(self):
        self.connection = "db_connection"
    
    async def get_user(self, user_id: int):
        return {"id": user_id, "name": "User"}

@app.get("/users/{user_id}")
async def get_user(user_id: int, db: Database = Depends()):
    return await db.get_user(user_id)
Dependency Injection Key Concepts:

• Depends() — Declares dependency, FastAPI automatically resolves and injects

• Reusability — Define once, use in multiple routes

• Dependency Chain — Dependencies can depend on other dependencies

• Caching — Within single request, same dependency called only once (if not async generator)

• Classes as Dependencies — Instantiate and pass dependencies via class constructor

06 • Security & Authentication

OAuth2, JWT, and Secure APIs

authentication.py 
from fastapi import FastAPI, Depends, HTTPException, status
from fastapi.security import OAuth2PasswordBearer, OAuth2PasswordRequestForm
from jose import JWTError, jwt
from datetime import datetime, timedelta
from passlib.context import CryptContext

app = FastAPI()

# Configuration
SECRET_KEY = "your-secret-key-change-this"
ALGORITHM = "HS256"
ACCESS_TOKEN_EXPIRE_MINUTES = 30

pwd_context = CryptContext(schemes=["bcrypt"], deprecated="auto")
oauth2_scheme = OAuth2PasswordBearer(tokenUrl="token")

class User(BaseModel):
    username: str
    email: Optional[str] = None
    full_name: Optional[str] = None
    disabled: Optional[bool] = None

class UserInDB(User):
    hashed_password: str

# Password hashing
def hash_password(password: str) -> str:
    return pwd_context.hash(password)

def verify_password(plain_password: str, hashed_password: str) -> bool:
    return pwd_context.verify(plain_password, hashed_password)

# JWT token creation
def create_access_token(data: dict, expires_delta: Optional[timedelta] = None) -> str:
    to_encode = data.copy()
    if expires_delta:
        expire = datetime.utcnow() + expires_delta
    else:
        expire = datetime.utcnow() + timedelta(minutes=15)
    
    to_encode.update({"exp": expire})
    encoded_jwt = jwt.encode(to_encode, SECRET_KEY, algorithm=ALGORITHM)
    return encoded_jwt

# Token validation
async def get_current_user(token: str = Depends(oauth2_scheme)):
    credentials_exception = HTTPException(
        status_code=status.HTTP_401_UNAUTHORIZED,
        detail="Could not validate credentials",
        headers={"WWW-Authenticate": "Bearer"},
    )
    try:
        payload = jwt.decode(token, SECRET_KEY, algorithms=[ALGORITHM])
        username: str = payload.get("sub")
        if username is None:
            raise credentials_exception
    except JWTError:
        raise credentials_exception
    
    # Fetch user from database
    user = get_user("fake_users_db", username)
    if user is None:
        raise credentials_exception
    return user

@app.post("/token")
async def login(form_data: OAuth2PasswordRequestForm = Depends()):
    # Validate username and password
    if not verify_password(form_data.password, "hashed_pass"):
        raise HTTPException(status_code=401, detail="Invalid credentials")
    
    access_token_expires = timedelta(minutes=ACCESS_TOKEN_EXPIRE_MINUTES)
    access_token = create_access_token(
        data={"sub": form_data.username},
        expires_delta=access_token_expires
    )
    return {"access_token": access_token, "token_type": "bearer"}

@app.get("/users/me")
async def read_users_me(current_user: User = Depends(get_current_user)):
    return current_user
Security Architecture:

• OAuth2PasswordBearer — Standard security scheme that extracts JWT from Authorization header

• Password Hashing — bcrypt never stores plain passwords, only hashes (bcrypt is slow by design)

• JWT Tokens — JSON Web Tokens contain encoded claims + expiration, validated on protected routes

• HTTPException(401) — Returns 401 Unauthorized when credentials invalid or missing

• Token Dependency — Automatically validates token on every protected route

Role-Based Access Control (RBAC)

rbac.py 
class User(BaseModel):
    username: str
    email: str
    role: str  # "admin", "user", "moderator"

async def get_admin(current_user: User = Depends(get_current_user)):

            detail="Not enough permissions"

Database Integration Pattern:

• SQLAlchemy ORM — Object-relational mapping translates Python classes to database tables

• get_db() Dependency — Yields session to route, ensures cleanup with try/finally

• CRUD Separation — Keep database queries in separate module for testability

• db.commit() — Persists changes to database (required for INSERT/UPDATE/DELETE)

• db.refresh() — Reloads object to get auto-generated IDs and defaults

08 • Error Handling & Exception Management

Custom Exceptions & Error Responses

exceptions.py 
from fastapi import FastAPI, HTTPException, status
from fastapi.responses import JSONResponse

app = FastAPI()

# Custom exception class
class ItemNotFound(Exception):
    def __init__(self, item_id: int):
        self.item_id = item_id

# Register custom exception handler
@app.exception_handler(ItemNotFound)
async def item_not_found_handler(request, exc):
    return JSONResponse(
        status_code=status.HTTP_404_NOT_FOUND,
        content={
            "error": "Item not found",
            "item_id": exc.item_id
        }
    )

@app.get("/items/{item_id}")
async def get_item(item_id: int):
    if item_id == 0:
        raise ItemNotFound(item_id=item_id)
    return {"item_id": item_id}

# HTTPException for standard HTTP errors
@app.get("/users/{user_id}")
async def get_user(user_id: int):
    if user_id < 1:
        raise HTTPException(
            status_code=status.HTTP_400_BAD_REQUEST,
            detail="User ID must be positive"
        )
    return {"user_id": user_id}

# Catch validation errors
from fastapi.exceptions import RequestValidationError

@app.exception_handler(RequestValidationError)
async def validation_exception_handler(request, exc):
    return JSONResponse(
        status_code=status.HTTP_422_UNPROCESSABLE_ENTITY,
        content={
            "error": "Validation failed",
            "details": exc.errors()
        }
    )
Error Handling Strategy:

• HTTPException — FastAPI's built-in exception for standard HTTP errors

• @exception_handler — Registers custom handlers for specific exception types

• Status Codes — Use appropriate codes (400, 401, 403, 404, 500, etc.)

• ValidationError Handling — Intercept Pydantic validation errors and customize response

• JSON Responses — Always return structured error responses with consistent format

09 • Middleware & Request/Response Lifecycle

Processing Hooks & Custom Middleware

middleware.py 
from fastapi import FastAPI
from starlette.middleware.base import BaseHTTPMiddleware
from starlette.requests import Request
import time
import uuid

app = FastAPI()

# Timing middleware
@app.middleware("http")
async def add_process_time_header(request: Request, call_next):
    start_time = time.time()
    response = await call_next(request)
    process_time = time.time() - start_time
    response.headers["X-Process-Time"] = str(process_time)
    return response

# Request tracking middleware
class RequestTrackingMiddleware(BaseHTTPMiddleware):
    async def dispatch(self, request: Request, call_next):
        request_id = str(uuid.uuid4())
        request.state.request_id = request_id
        
        response = await call_next(request)
        response.headers["X-Request-ID"] = request_id
        return response

# Add to application
app.add_middleware(RequestTrackingMiddleware)

# CORS middleware
from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],  # Specify domains in production
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

# Startup and shutdown events
@app.on_event("startup")
async def startup_event():
    print("Server starting...")
    # Initialize resources

@app.on_event("shutdown")
async def shutdown_event():
    print("Server shutting down...")
    # Cleanup resources
Middleware & Lifecycle:

• @app.middleware("http") — Simple middleware for basic request/response processing

• BaseHTTPMiddleware — Class-based middleware for complex logic

• call_next(request) — Passes control to next middleware or route handler

• request.state — Attach data to request for access in routes

• Startup/Shutdown Events — Run code when server starts/stops

Repository Pattern for Data Access

repository.py 
from abc import ABC, abstractmethod
from sqlalchemy.orm import Session

class BaseRepository(ABC):
    def __init__(self, db: Session):
        self.db = db
    
    @abstractmethod
    async def get_by_id(self, id: int): pass
    
    @abstractmethod
    async def create(self, obj): pass

class UserRepository(BaseRepository):
    async def get_by_id(self, user_id: int):
        return self.db.query(UserModel).filter(UserModel.id == user_id).first()
    
    async def create(self, username: str, email: str):
        user = UserModel(username=username, email=email)
        self.db.add(user)
        self.db.commit()
        return user

def get_user_repository(db: Session = Depends(get_db)):
    return UserRepository(db)

@app.get("/users/{user_id}")

class UserService:
    def __init__(self, repo: UserRepository):
        self.repo = repo
    
    async def register_user(self, username: str, email: str, password: str):
        # Business logic: validation, password hashing, etc.
        hashed_password = hash_password(password)
        user = await self.repo.create(username, email)
        return user
    
    async def authenticate(self, username: str, password: str):
        user = await self.repo.get_by_username(username)
        if not verify_password(password, user.hashed_password):
            raise ValueError("Invalid credentials")
        return user
